# Third-party references

Hunt Automator interoperates with, but does not bundle, the following plugins:

- vnavmesh — movement/pathfinding IPC
- RotationSolverReborn — combat rotation
- HuntHelper — optional hunt-train IPC
- TeleporterPlugin — teleport IPC
- HuntBuddy — optional companion UI/data reference

Some factual hunt-map coordinates in `Data/DailyLocationDatabase.cs` were transcribed/adapted from HuntBuddy's public location table for interoperability and routing. HuntHelper's public source/API was consulted for its IPC contract; HuntHelper is MIT licensed (copyright imaginary-png, 2022).

No third-party binaries are included in this archive.
